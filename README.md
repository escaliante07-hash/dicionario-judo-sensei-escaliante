# Dicionário do Judô — Sensei Rodrigo Escaliante

Aplicativo web instalável (PWA) para consulta de técnicas Kodokan, termos do judô, Kihon, números e pronúncias.

## Arquivos

- `dist/index.html`: interface e lógica do aplicativo
- `dist/data.json`: conteúdo e camada de leitura vocal
- `dist/manifest.webmanifest`: configuração instalável
- `dist/sw.js`: service worker e cache
- `dist/icons/`: ícones e identidade visual

## Hospedagem
